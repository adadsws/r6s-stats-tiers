# R6 RPM Chart And Lowest Letter Tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a two-sheet automatic-firearm RPM chart and normalize raw `boof` ratings to the current lowest visible letter tier throughout every generated project workbook.

**Architecture:** Add a small `r6_tiers.py` module as the single source of truth for visible tiers, colors, and raw-tier normalization. Keep source parsing and Huiji asset preparation in `r6_tier_chart.py`; implement the new stable RPM sort and five-card renderer in `r6_rpm_chart.py`, reusing the validated card data and image helpers.

**Tech Stack:** Python 3.9+, openpyxl 3.x, Pillow, standard-library unittest, Microsoft Excel COM for compatibility and visual verification.

## Global Constraints

- Preserve raw Athieno source labels and scores, including `boof=0`.
- Visible tiers are `S, A, B, C, D, F`; raw `boof` displays as the final visible letter tier.
- RPM sorting uses the maximum across all primary and secondary automatic-weapon RPMs, but never displays that maximum or a numeric rank.
- Each side is sorted independently; ties preserve source workbook order and operators without automatic weapons sort last.
- The new card shows the existing compact facts and a colored box containing only the visible tier letter.
- Keep five cards per row and use official cached Huiji Badge and gadget icons.
- Preserve unrelated workspace changes; `.git` is not recognized as a repository, so do not attempt commits.
