# 干员卡片左右半区对齐计划

## 需求

- 将 `视频 Tier` 与速度放在同一个单元格中。
- 前四行详情统一分成左右等宽两半，所有竖向分界线对齐。
- 保留当前无干员名字、五行卡片、主武器三行、副喷一行、副武器两行以及底部单行七装备槽。
- XLSX、PDF 和 PNG 保持一致，卡片宽高及分页容量不变。

## 布局解释

前四行详情区使用同一条中线：

1. 左：`<视频 Tier> · <速度>`；右：`主狙`
2. 左：`主要武器 1：射速 + 图标`；右：`副喷`
3. 左：`主要武器 2：射速 + 图标`；右：`副武器 1：射速 + 图标`
4. 左：`主要武器 3：射速 + 图标`；右：`副武器 2：射速 + 图标`
5. 七个等宽次要装备槽横跨整卡

- 徽章仍位于详情区左侧并跨前四行；“左右两半”指徽章右侧的详情区。
- 第五行继续按 7 个等宽槽划分，不强行拆成 `4 + 3` 两个不等宽半区。
- 第一行左侧文字采用 `A · 3速` 格式；补丁标记继续附着在视频 Tier 后，例如 `A~ · 3速`。
- 空武器行继续留空；主狙和副喷缺失时保留现有 `主狙 -`、`副喷 -` 显示。

## 方案比较

### A. 详情区统一二等分（推荐）

- XLSX 中前四行均将 6 个详情列合并为左 3 列和右 3 列。
- PDF 中前四行均使用相同的左右半宽列。
- 优点：中线完全一致，改动集中，不影响徽章和七装备槽。

### B. 整张卡片二等分

- 将徽章也纳入左半区，字段需围绕徽章重新排布。
- 缺点：压缩主要武器空间，改变已确认的徽章跨行结构。

### C. 底部装备也按左右两半分组

- 左侧放 4 个槽，右侧放 3 个槽。
- 缺点：槽宽不一致，破坏当前单行七等槽和内部对齐。

采用方案 A；用户回复 `v` 后即确认详情区二等分、底部七槽保持不变。

## 实施设计

### XLSX

- 修改 `src/r6_report/leaderboards.py`：
  - 第一行左侧合并前 3 个详情列，写入组合后的 Tier 与速度；右侧合并后 3 个详情列，显示主狙。
  - 第 2 至第 4 行沿用同样的左 3 / 右 3 列边界。
  - Tier 配色应用到第一行左半区，同时保持组合文字清晰可读。
  - 调整主狙图标锚点，使其适应扩展后的右半区。
  - 其余徽章、主副武器和七装备槽位置不变。

### PDF / PNG

- 修改 `src/r6_report/pdf_leaderboards.py`：
  - 详情表从第一行三等分改为全部四行左右二等分。
  - 第一行左侧显示组合 Tier/速度并使用 Tier 背景色，右侧显示主狙。
  - 保持 62 mm 详情区、15 mm 徽章区、77 mm × 33 mm 卡片尺寸。
  - PNG 继续直接由 PDF 栅格化。

### 测试与文档

1. 先修改 XLSX 结构测试，断言第一行只有左右两个详情单元格、组合文字格式正确、四行中线一致，并确认旧实现失败。
2. 实施 XLSX 最小改动并运行相关测试。
3. 先修改 PDF 结构测试，断言四行均为左右二等分、组合文字与 Tier 色块位于左侧，并确认旧实现失败。
4. 实施 PDF 最小改动并运行相关测试。
5. 更新 `README.md` 与 `CHANGELOG.md` 的布局说明。
6. 运行 `python -m unittest discover -s tests -v`。
7. 从现有 `inputs/` 快照离线生成 5 份 XLSX、5 份三页 PDF 和 15 张 PNG 到 `~outputs/`。
8. 检查 IQ、Striker、Sentry 以及缺失字段卡片，确认前四行中线对齐且无文字、图标越界。
9. 同步通过检查的固定 PDF 和预览图到 `docs/`，提交实现并归档本计划。

## 验收标准

- 第一行左侧只显示组合后的 `视频 Tier · 速度`，不再存在独立速度格和独立 Tier 格。
- 第一行右侧只显示主狙状态及对应图标。
- 前四行详情区的垂直中线处于相同位置。
- 主武器、副喷和副武器的行序保持不变。
- 第五行仍为 7 个等宽、有分界线的装备槽。
- 卡片不显示干员名字，尺寸与分页不变。
- 106 项现有测试及新增对齐断言全部通过，三种输出生成和视觉检查通过。

## 用户决策

- `v`：采用推荐方案 A，按 `Tier · 速度` 格式实施。
- 如希望显示为 `速度 · Tier` 或要求底部也拆成左右两组，请在批准前直接说明。
