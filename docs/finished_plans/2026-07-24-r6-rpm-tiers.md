# R6 RPM Tier Rows And Video Badges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the RPM workbook match the traditional Tier List structure, with Roman RPM tiers on the left and Athieno video tiers in compact badges beside operator names.

**Architecture:** Keep the fixed RPM classifier and source-card model. Add an RPM-tier grouping helper, reshape the RPM renderer into left-band tier sections, and repurpose the existing compact badge images to display `S/A/B/C/D/F` from each card's Athieno score.

**Tech Stack:** Python 3.9+, openpyxl 3.x, Pillow, standard-library `unittest`, Microsoft Excel COM for visual verification.

## Global Constraints

- Left-side RPM tiers are `Ⅰ`, `Ⅱ`, `Ⅲ`, `Ⅳ`, in that order.
- Fixed thresholds remain `Ⅰ >=1000`, `Ⅱ 850-999`, `Ⅲ 750-849`, `Ⅳ <750 or no automatic weapon`.
- Thresholds never recalculate from future data.
- Each RPM tier wraps after five operator cards.
- Within each RPM tier, sort by the operator's highest primary-or-secondary automatic RPM descending; ties preserve Wiki source order.
- Operators without automatic weapons are in `Ⅳ` and remain after numeric RPM values.
- Each card shows its Athieno video tier `S/A/B/C/D/F` in a compact colored badge immediately after the operator name.
- The card badge never displays `Ⅰ/Ⅱ/Ⅲ/Ⅳ`.
- RPM tier colors are red `E74C3C`, orange `F39C12`, yellow `F1C40F`, gray `7F8C8D`.
- Video-tier badge colors come from `r6_tiers.TIER_COLORS`.
- Statistics and traditional Tier List workbooks remain unchanged.
- `补丁说明` worksheets remain unfrozen.
- The workspace is not a Git repository; do not attempt commits.

```python
def group_cards_by_rpm_tier(
    cards: Iterable[OperatorCard],
) -> Mapping[str, Tuple[OperatorCard, ...]]:
    grouped: Dict[str, List[OperatorCard]] = {
        tier_name: [] for tier_name in RPM_TIER_ORDER
    }
    for card in sort_cards_by_rpm(cards):
        grouped[rpm_tier_for_card(card)].append(card)
    return {
        tier_name: tuple(grouped[tier_name])
        for tier_name in RPM_TIER_ORDER
    }
```
