# R6 自动枪械射速榜与最低字母档统一设计

## 目标

新增一个从当前 `r6_operator_stats.xlsx` 生成的自动枪械射速榜工作簿，并统一整个项目中 `boof` 的展示规则。

## 项目统一阶层规则

- 原始评分来源继续保留七档及分数：`S=100`、`A=85`、`B=70`、`C=55`、`D=40`、`F=20`、`boof=0`。
- `boof` 是原始来源标签，不再作为可见阶层。
- 展示层把 `boof` 归入当前最低字母档。当前可见字母顺序为 `S、A、B、C、D、F`，因此 `boof` 干员显示为 `F`，并使用 F 的颜色。
- 最低字母档从统一的可见阶层顺序推导，避免以后阶层名称变化时逐处修改。
- 现有评分工作簿仍显示原始数值 `0`，但其评分单元格使用当前最低字母档的颜色。
- 现有 Tier 简图移除独立的 `BOOF` 行，将原 `boof` 干员放入最低字母档行。

## 新射速榜

- 默认输出：`r6_operator_rpm_chart.xlsx`。
- 工作表：`进攻方射速榜`、`防守方射速榜`。
- 每方独立排序，不混合进攻方和防守方。
- 每名干员的排序值为主手和副手全部自动枪械 RPM 的最大值。
- 排序值只用于排序，不显示在卡片上。
- 按排序值降序；没有任何自动枪械的干员排最后；相同排序值保持来源工作簿顺序。
- Tier 不参与射速排序，因此最低档干员仍按其自动枪械射速出现在对应位置。

## 卡片布局

- 传统横向紧凑卡片，每行五名干员。
- 卡片显示官方 Badge、干员名称、速度、主手自动枪械全部 RPM、副手自动枪械全部 RPM、`主手半自`、`副喷`和全部次要装备图标。
- 不显示最高射速，不显示 `#1` 等排名数字。
- 每张卡片右侧放一个独立彩色方框，只显示可见 Tier 字母。
- 原始 `boof` 干员的方框显示 `F`，颜色与 F 档一致。
- 工作表隐藏网格线，冻结标题区域，使用横向打印并缩放为单页宽、单页高。

## 实现边界

- 新增 `r6_rpm_chart.py` 和 `run_r6_rpm_chart.bat`。
- 复用 `r6_tier_chart.py` 已验证的九列表头解析、官方 Badge、装备图标缓存和图片锚点逻辑。
- 在共享模块中提供统一的可见阶层规范化函数，现有 Tier 简图和新射速榜都调用它。
- 不修改人工核对的 `data/athieno_y11s2.json` 原始标签与分数。
- 同步更新 README、CHANGELOG、项目 Skill、测试和已生成的两个简图工作簿。

## 错误处理

- 缺失输入工作簿、必需表头、Badge 或装备图标时明确失败。
- 非法速度、未知评分、重复干员和损坏图片继续沿用现有严格校验。
- 如果干员没有任何自动枪械，排序键使用空值并稳定放到榜尾，卡片主副射速显示 `-`。

## 测试与验证

- 测试原始 `boof=0` 在所有展示入口都规范化为当前最低字母档。
- 测试现有 Tier 简图只有六个可见阶层，原 Boof 干员进入 F 行。
- 测试射速排序同时考虑主手和副手，副手更快时以副手排序。
- 测试同速稳定排序、无自动枪械置底、每五名换行和 Tier 彩色方框。
- 运行完整 `unittest`、Skill 校验和真实工作簿结构审计。
- 使用 Microsoft Excel 打开两个最终工作簿，并将新射速榜导出为 PNG 做视觉检查。
