# R6 主手自动枪械射速榜设计

## 目标

在现有 `r6_operator_rpm_chart.xlsx` 中保留综合自动枪械射速榜，并新增两张只以主手自动枪械为依据的射速榜：

- `进攻方主手射速榜`
- `防守方主手射速榜`

新榜继续使用传统横向 Tier List 排版。左侧显示主手射速等级 `Ⅰ/Ⅱ/Ⅲ/Ⅳ`，右侧干员卡片保留官方 Badge、现有简写信息、次要装备图标，以及名字右侧的 Athieno 视频评级彩色徽标。

## 数据口径

- 每名干员只取 `primary_rpms` 中的最高值作为主手射速排序值。
- `secondary_rpms` 不参与新榜分档或排序。
- 没有主手自动枪械的干员仍保留，归入 `Ⅳ` 并排在所有数值射速之后。
- 同射速时保持来源工作簿顺序。
- 卡片现有信息不删减，因此仍可看到主手和副手自动枪械射速、主手半自、副喷和次要装备。

## 固定四档

先将当前 77 名进攻方和防守方干员合并，按主手最高自动射速统计；在不拆分相同射速的前提下，选择最接近四等分的三个分界并固定：

| 等级 | 主手最高自动射速 | 当前人数 |
| --- | --- | ---: |
| `Ⅰ` | `>= 860` | 20 |
| `Ⅱ` | `780-859` | 20 |
| `Ⅲ` | `700-779` | 18 |
| `Ⅳ` | `< 700` 或无主手自动枪械 | 19 |

以后重新生成工作簿时不动态重算阈值。

## 工作簿结构

工作表顺序固定为：

1. `进攻方射速榜`
2. `防守方射速榜`
3. `进攻方主手射速榜`
4. `防守方主手射速榜`
5. `补丁说明`

两张新表沿用现有射速榜样式：

- 每个射速等级从上到下排列。
- 每行最多五张干员卡片，超出后在同一等级内换行。
- 左侧等级色块跨越该等级的全部卡片行。
- 名字右侧显示 Athieno 视频评级 `S/A/B/C/D/F` 彩色徽标。
- 表尾保留“除评分外其他信息已是最新”的状态说明。
- `补丁说明` 保持不冻结窗格。

## 实现边界

- 保留现有综合榜的 `1000 / 850 / 750` 固定分界和行为。
- 为主手榜增加独立的取值、排序、分档函数，避免改变综合榜。
- 抽取可复用的工作表渲染参数，使两种榜共享布局而保持各自标题、工作表名和分档规则。
- 项目脚本和项目内 Skill 脚本保持同步。

## 测试与验证

- 单元测试主手最高射速只读取 `primary_rpms`。
- 覆盖 `860 / 859 / 780 / 779 / 700 / 699` 边界及无主手自动枪械。
- 验证副手射速不会影响主手榜排序和分档。
- 验证四档按 `20 / 20 / 18 / 19` 覆盖当前 77 名干员。
- 验证工作簿新增两张表、顺序正确、原综合榜未变化。
- 验证新表每五名换行、视频评级徽标、状态行、打印区域和冻结窗格。
- 运行全量 `unittest`，重新生成实际工作簿，并使用 Microsoft Excel 打开及目视检查四张榜和补丁说明。
