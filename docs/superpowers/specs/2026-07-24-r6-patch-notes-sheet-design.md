# R6 补丁说明工作表设计

## 目标

为项目生成的三个工作簿分别新增一张独立的 `补丁说明` 工作表：

- `r6_operator_stats.xlsx`
- `r6_operator_tier_chart.xlsx`
- `r6_operator_rpm_chart.xlsx`

现有数据表、Tier 简图和射速榜的主体内容、顺序及布局保持不变；每张原有工作表的最后一行追加数据状态说明。补丁说明只比较 Athieno 视频评分所对应的 Y11S2 上线版（2026-06-02）与当前最新补丁 Y11S2.2（2026-07-14）。

## 原有工作表状态行

六张原有工作表都在实际内容结束后空一行，并在最下方追加：

`数据状态：除 Athieno Y11S2 视频评分外，本表其他信息均按生成时的灰机 Wiki 最新数据更新。`

- 统计工作簿的状态行放在 Excel 筛选表格之外，不作为干员数据。
- Tier 简图和射速榜的状态行放在卡片区域之外。
- 状态行跨工作表实际使用宽度合并，使用浅灰底、斜体和自动换行。
- 打印区域扩展到状态行。
- 状态行必须是工作表最后一个非空行。

## 工作表结构

`补丁说明` 放在每个工作簿的最后，顶部依次包含：

1. 标题：`Y11S2 视频评分后续补丁说明`
2. 状态说明：`除 Athieno Y11S2 视频评分外，干员、速度、武器、装备、图标与补丁信息均按生成时的灰机 Wiki 最新数据更新。`
3. 评分说明：补丁变化只用于提示评分可能过时，不自动修改 Athieno 原始分数。
4. 来源链接：
   - 灰机 Wiki 更新补丁总表
   - 灰机 Wiki Y11S2.1 更新补丁
   - Ubisoft Y11S2.1 Patch Notes
   - 灰机 Wiki Y11S2.2 更新补丁
   - Ubisoft Y11S2.2 Mid-Season Patch Notes

来源名称显示为可点击超链接，单元格同时保留完整 URL，方便复制和审计。

## 补丁表格

表格列固定为：

1. `方向`
2. `补丁`
3. `日期`
4. `干员/对象`
5. `视频评分`
6. `更新内容`

方向分为：

- `增强`：绿色填充。
- `削弱`：红色填充。
- `混合`：黄色填充。

视频评分显示为可见 Tier 与原始数值，例如 `B / 70`。补丁数据不产生新评分，也不改变 `data/athieno_y11s2.json`。

## 收录范围

### Y11S2.1

- 削弱：Dokkaebi、Thorn。
- 增强：Sens、IQ、Ash、Finka、Thatcher、Zero。
- 间接增强：防弹摄像头 EMP 范围提升。为每名受影响且在当前报告中的干员单独生成一行，以便显示对应视频评分。
- 影响强度的修复：Solis 归为削弱；Solid Snake 同时包含异常跨楼层侦测修复和技能可靠性修复，归为混合。

### Y11S2.2

- 增强：Wamai、Zofia、Rauora、Melusi、Twitch、Lesion。
- 混合：Dokkaebi、Jäger。Dokkaebi 获得按目标独立冷却，但同一目标冷却延长；Jäger 提升速度并降低生命值，同时改善 416-C 后坐力。

地图、匹配、音频、界面和不影响干员强度的普通修复不进入表格。

## 代码结构

新增共享模块 `r6_patch_notes.py`：

- 保存补丁元数据、来源 URL 和结构化变更记录。
- 定义统一的补丁方向和显示颜色。
- 接收 `干员名称 -> 视频分数` 映射，生成评分显示。
- 提供一个工作表写入函数，由三个生成器调用。
- 对未知方向、重复记录、缺失受影响干员评分或无效 URL 立即报错。

三个生成器分别从已有数据构建评分映射：

- `r6_operator_stats.py` 使用已加载的 `OperatorRating`。
- `r6_tier_chart.py` 和 `r6_rpm_chart.py` 使用输入工作簿解析出的 `OperatorCard.score`。

工作表名称冲突时立即失败，不覆盖已有工作表。

共享模块同时提供状态行写入函数，三个生成器使用同一段固定文字和样式，避免工作簿之间出现不同版本的声明。

## 格式与打印

- 使用项目现有深色标题风格，保持与三个工作簿一致。
- 状态说明和评分说明跨六列合并、自动换行。
- 来源区使用蓝色带下划线超链接。
- 表头冻结，启用自动筛选。
- 更新内容列自动换行，按内容调整行高并限制列宽。
- 页面使用横向打印、单页宽度；打印区域仅覆盖实际说明内容。
- 不向补丁说明页嵌入图片。

## 测试与验证

- 先增加失败测试，要求三个生成器都创建 `补丁说明`。
- 验证三个工作簿各自保留原有两张工作表，并把 `补丁说明` 放在最后。
- 验证六张原有工作表的最后一个非空行均为统一状态说明，且状态行不进入统计工作簿的 Excel 表格范围。
- 验证标题、状态说明、六列表头、Y11S2.1/Y11S2.2 日期和全部来源超链接。
- 验证增强、削弱、混合三类颜色及代表性记录。
- 验证受防弹摄像头增强影响的干员逐行显示视频评分。
- 验证缺失评分、重复工作表和无效补丁数据明确失败。
- 运行完整 `unittest`，同步项目 Skill 内置脚本并通过 Skill 校验。
- 重新生成三个正式工作簿，用 Microsoft Excel 只读打开，并渲染三张 `补丁说明` 工作表进行视觉检查。
