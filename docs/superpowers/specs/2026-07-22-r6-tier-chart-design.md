# R6 评分阶层 XLSX 简图设计

## 目标

新增脚本读取当前 `r6_operator_stats.xlsx`，生成 `r6_operator_tier_chart.xlsx`。输出包含“进攻方简图”和“防守方简图”两个工作表，以传统横向 Tier List 形式展示干员评分阶层和紧凑装备摘要。

## 输入与输出

- 默认输入：项目目录下的 `r6_operator_stats.xlsx`。
- 默认输出：项目目录下的 `r6_operator_tier_chart.xlsx`。
- 输入必须包含当前九列，脚本按表头名称读取，不依赖固定列号。
- 评分必须属于 `100、85、70、55、40、20、0`；可见映射为 `S、A、B、C、D、F、F`，其中原始 `boof=0` 归入当前最低字母档 F。
- 输出仅包含“进攻方简图”和“防守方简图”。

## 布局

- 可见阶层从上到下固定为 `S、A、B、C、D、F`。
- 每个阶层左侧使用纵向合并的阶层标签色块。
- 干员从左到右排列，每行最多五名；超过五名时在同一阶层内换行。
- 每名干员占一个固定宽度的卡片区域，所有卡片尺寸一致。
- 工作表隐藏网格线，使用横向页面、单页宽度打印设置，并冻结标题区域。
- 阶层标签使用评分颜色；卡片使用浅色背景、细边框和稳定行列尺寸，避免图片或文字改变布局。

## 干员卡片

每张卡片包含：

1. 灰机 Wiki 官方 Badge。
2. 干员名称。
3. 紧凑状态行，例如：`2速 · 主 800/700 · 副 1270`。
4. 有无状态行，例如：`主手半自 ✓ · 副喷 ✓`。
5. 次要装备图标行；所有次要装备使用灰机 Wiki 图标，图标旁显示数量。

显示规则：

- `主`：提取“主手自动枪械”单元格中的所有 RPM，以 `/` 连接；没有则显示 `-`。
- `副`：提取“副手自动枪械”单元格中的所有 RPM，以 `/` 连接；没有则显示 `-`。
- `主手半自`：判断“主手半自”是否存在；源数据只收录 `equipment == 1`、`firerate == 0` 且 `projectile == 1` 的单弹丸非自动枪械，包含主手独头弹霰弹。
- `副喷`：判断“副手霰弹”是否存在；源数据只收录副手中 `projectile > 1` 的多弹丸武器。
- 次要装备：解析名称和数量，使用 Wiki 图标和阿拉伯数字；缺少数量时只显示图标。

## 图标

- 干员使用项目已有 `assets/operator-icons/badge/` 官方 Badge。
- 次要装备图标从灰机 Wiki 只读 API 解析并缓存到 `assets/gadget-icons/`。
- 为装备名称维护规范化映射，兼容 Wiki 中的同义写法，例如手雷/破片手榴弹、烟雾弹/烟雾手榴弹。
- 找不到关键装备图标时明确报错，不静默替换第三方素材。

## 脚本接口

新增 `r6_tier_chart.py`：

```powershell
python r6_tier_chart.py [--input PATH] [--output PATH] [--icons-dir PATH] [--gadget-icons-dir PATH]
```

脚本内部拆分为输入解析、字段压缩、装备图标准备、阶层布局和工作簿输出五部分。

## 错误处理

- 缺失工作表、缺失必要表头、重复干员、未知评分、非数字速度或缺失干员 Badge 时立即失败。
- 无自动枪械、无主手半自或无副手霰弹是正常状态，分别显示 `-`。
- 次要装备字符串无法解析或图标无法解析时输出具体干员和装备名称。
